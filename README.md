## ✨ About the Project

> **GDG On Campus TIU** is the home of the Google Developer Group at **Techno India University, West Bengal**, a student-led community where curious minds learn, build and grow with Google technologies.

This repository contains a **modern, responsive redesign** of the chapter's website. It is built to feel alive, with **interactive UI, buttery-smooth animations, event showcases and domain team profiles**, while staying fast and easy to maintain.

## ⚡ Getting Started

### Prerequisites

- [Bun](https://bun.sh/) (recommended, a `bun.lock` is included) **or** Node.js 18+ with npm

### 1️⃣ Clone the repository

```bash
git clone https://github.com/himangshukumbhakar58-cpu/gdg-on-campus-tiu-website.git
cd gdg-on-campus-tiu-website
```

### 2️⃣ Install dependencies

```bash
bun install
# or
npm install
```

### 3️⃣ Set up environment variables

```bash
cp .env.example .env.local
```

Then open `.env.local` and fill in the values (see [Environment Variables](#-environment-variables)).

### 4️⃣ Start the dev server

```bash
bun run dev
# or
npm run dev
```

Open **http://localhost:3000** and you're live. 🎉

## 🔐 Environment Variables

All required variables are listed in [`.env.example`](./.env.example). Copy it to `.env.local` and add your own values.

> ⚠️ **Never commit your real `.env` / `.env.local` file or API keys.** They are already covered by `.gitignore`.

## 📜 Available Scripts

| Command | What it does |
|:--|:--|
| `bun run dev` | Starts the Vite dev server on port **3000** |
| `bun run build` | Creates an optimized production build in `dist/` |
| `bun run preview` | Serves the production build locally |
| `bun run lint` | Type-checks the project with `tsc --noEmit` |
| `bun run clean` | Removes the `dist/` build output |

## ☁️ Deployment

The site is deployed on **Vercel** and is live at:

### 👉 [**https://gdg-on-campus-tiu-website.vercel.app/**](https://gdg-on-campus-tiu-website.vercel.app/)

To deploy your own copy:

1. Fork this repository
2. Import it into [Vercel](https://vercel.com/new)
3. Add the environment variables from `.env.example` in the Vercel dashboard
4. Click **Deploy** 🚀
